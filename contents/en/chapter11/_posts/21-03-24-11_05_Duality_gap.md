In unconstrained optimization, knowing when to stop an iterative solver is notoriously tricky: a tiny gradient $$\|\nabla f(x)\| \le 10^{-5}$$ does not by itself tell you how close $$f(x)$$ is to $$f^\star$$ if the function is very flat. Duality solves this stopping problem with mathematical perfection: whenever an algorithm produces a primal-feasible $$x$$ and a dual-feasible $$(u, v)$$, the observable **duality gap** $$f(x) - g(u, v)$$ rigorously upper-bounds the unobservable true error $$f(x) - f^\star$$!

## Background Knowledge Map: The Duality Gap as an Exact Stopping Certificate

- **Pillar 1 — The Sandwich Inequality:** Weak duality $$g(u, v) \le f^\star \le f(x)$$ immediately implies $$0 \le f(x) - f^\star \le f(x) - g(u, v)$$ and $$0 \le g^\star - g(u, v) \le f(x) - g(u, v)$$. Both primal and dual errors are simultaneously bounded by one computable number!
- **Pillar 2 — Zero Gap Implies Joint Optimality:** If you ever find a feasible pair $$(x, u, v)$$ with $$f(x) - g(u, v) = 0$$, then $$f(x) = f^\star = g^\star = g(u, v)$$: *both* $$x$$ and $$(u, v)$$ are guaranteed globally optimal, and strong duality holds automatically.
- **Pillar 3 — Non-Asymptotic Stopping Rule in Solvers:** Modern convex solvers (interior-point methods, coordinate descent for Lasso, dual ascent) terminate as soon as $$f(x^{(k)}) - g(u^{(k)}, v^{(k)}) \le \varepsilon$$, guaranteeing $$\varepsilon$$-suboptimality with zero heuristic guesswork.
- **Pillar 4 — Constructing Dual-Feasible Points from Primal Iterates:** Even in primal-only solvers (like ISTA for Lasso), simple dual scaling projects the residual onto the dual feasible set in $$O(n)$$ time, unlocking real-time duality-gap monitoring and safe feature screening (GAP Safe rules).

### Step-by-Step Worked Example (Read Slowly): Certifying $$\varepsilon$$-Optimality Without Knowing $$f^\star$$

Suppose we minimize $$f(x) = \frac{1}{2}x^2 - 4x$$ subject to $$x \le 2$$ (i.e., $$h(x) = x - 2 \le 0$$). From $$L(x, u) = \frac{1}{2}x^2 - (4 - u)x - 2u$$, minimizing over $$x$$ gives $$x = 4 - u$$ and dual function $$g(u) = -\frac{1}{2}(4 - u)^2 - 2u$$ for $$u \ge 0$$.

1. **Evaluate at an intermediate primal–dual iterate $$x^{(k)} = 1.8$$ (feasible: $$1.8 \le 2$$) and $$u^{(k)} = 1.5$$ (feasible: $$1.5 \ge 0$$):**
   - Primal value: $$f(1.8) = \frac{1}{2}(1.8)^2 - 4(1.8) = 1.62 - 7.20 = -5.58$$.
   - Dual value: $$g(1.5) = -\frac{1}{2}(4 - 1.5)^2 - 2(1.5) = -\frac{1}{2}(6.25) - 3.0 = -3.125 - 3.0 = -6.125$$.
   - **Duality gap:** $$f(1.8) - g(1.5) = -5.58 - (-6.125) = 0.545$$.
   - Without knowing $$f^\star$$, we immediately know $$f^\star \in [-6.125,\; -5.58]$$ and $$f(1.8) - f^\star \le 0.545$$!
2. **Evaluate at $$x^\star = 2$$ and $$u^\star = 2$$:**
   - Primal value: $$f(2) = \frac{1}{2}(4) - 8 = -6.0$$.
   - Dual value: $$g(2) = -\frac{1}{2}(2)^2 - 2(2) = -2 - 4 = -6.0$$.
   - **Duality gap:** $$-6.0 - (-6.0) = 0$$, certifying exact optimality of both $$x^\star = 2$$ and $$u^\star = 2$$!

If the primal problem has value $$f(x)$$ at $$x$$, and the dual problem has value $$g(u,v)$$ at $$u,v$$, then the difference $$f(x) - g(u,v)$$ is called the duality gap.

Meanwhile, these feasible values always satisfy the following relation
>
$$
\begin{equation}
f(x) - f^* \leq f(x) - g(u,v), 
\end{equation}
$$

If the duality gap is $$0$$, then $$x$$ is an optimal solution of the primal problem and $$u,v$$ are optimal for the dual problem.

Also, if the duality gap satisfies $$f(x)-g(u,v) \leq \epsilon$$, it implies $$f(x) -f^* \leq \epsilon$$, so algorithms that solve problems iteratively can use the duality gap as a stopping criterion.
