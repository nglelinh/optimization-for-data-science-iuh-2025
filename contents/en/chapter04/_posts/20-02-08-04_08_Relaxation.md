When a door is locked by a hard nonconvex constraint—like requiring variables to be binary $$\{0, 1\}$$ or a matrix to have rank 1—exact optimization can take exponential time. *Relaxation* is the art of widening the feasible set $$C$$ to a larger, friendlier convex set $$\tilde{C} \supseteq C$$ so that a solver can compute a guaranteed lower bound in polynomial time—and sometimes, remarkably, the relaxed solution lands right back inside $$C$$ and solves the hard problem exactly!

## Key ideas: How Convex Relaxation Bridges Hard and Tractable Problems

1. **Guaranteed Lower Bounds (for Minimization)**: Because $$\tilde{C} \supseteq C$$ gives the optimizer strictly more choices, the relaxed optimal value always satisfies $$\tilde{f}^\star \le f^\star$$. This bound is priceless: if a heuristic gives a feasible solution $$x_{\mathrm{heur}} \in C$$, the gap $$f(x_{\mathrm{heur}}) - \tilde{f}^\star$$ certifies how close you are to global optimality.
2. **Exactness Certificate**: If the minimizer $$\tilde{x}^\star$$ of the relaxed problem happens to satisfy the dropped constraints ($$\tilde{x}^\star \in C$$), then $$\tilde{f}^\star = f(\tilde{x}^\star) \ge f^\star \ge \tilde{f}^\star$$, proving $$\tilde{x}^\star$$ is an *exact global minimizer* of the original hard problem.
3. **Relaxing Non-Affine Equalities to Inequalities**: A non-affine equality $$g(x) = 0$$ (where $$g$$ is convex) makes a problem nonconvex because $$g(x) \ge 0$$ is generally nonconvex. Relaxing $$g(x) = 0$$ to $$g(x) \le 0$$ restores convexity—for instance, relaxing the unit sphere $$\|x\|_2 = 1$$ to the unit ball $$\|x\|_2 \le 1$$.
4. **Tightness vs. Tractability Trade-Off**: Replacing a discrete set $$\{0, 1\}^n$$ with its convex hull $$[0, 1]^n$$ (LP relaxation) or replacing $$\operatorname{rank}(X) = 1$$ with $$X \succeq 0$$ (SDP relaxation) balances how close $$\tilde{f}^\star$$ is to $$f^\star$$ against how fast we can solve the relaxed problem.

### Worked example: Relaxing a Nonconvex Sphere Constraint to a Convex Ball

Consider the nonconvex problem of minimizing a linear function on the unit circle:
$$\text{minimize}_{x \in \mathbb{R}^2} \quad f(x) = -3x_1 - 4x_2 \quad \text{subject to} \quad x_1^2 + x_2^2 = 1.$$

1. **Identify why it is nonconvex**: The equality constraint $$x_1^2 + x_2^2 = 1$$ is non-affine—the midpoint of $$(1, 0)$$ and $$(-1, 0)$$ is $$(0, 0)$$, which does not lie on the unit circle.
2. **Form the convex relaxation**: Replace the equality $$x_1^2 + x_2^2 = 1$$ with the convex quadratic inequality $$x_1^2 + x_2^2 \le 1$$ (widening the circle $$C$$ to the filled unit disk $$\tilde{C}$$):
   $$\text{minimize}_{x \in \mathbb{R}^2} \quad -3x_1 - 4x_2 \quad \text{subject to} \quad \|x\|_2^2 \le 1.$$
3. **Solve the relaxed convex problem**: By the Cauchy–Schwarz inequality,
   $$-3x_1 - 4x_2 = -(3, 4) \cdot (x_1, x_2) \ge -\|(3, 4)\|_2 \|x\|_2 = -5 \|x\|_2 \ge -5,$$
   with equality achieved at $$\tilde{x}^\star = \frac{1}{5}(3, 4) = (0.6, 0.8)$$, giving $$\tilde{f}^\star = -5$$.
4. **Check exactness**: Test whether $$\tilde{x}^\star$$ lies in the original nonconvex set $$C$$:
   $$0.6^2 + 0.8^2 = 0.36 + 0.64 = 1.$$
   It does! Because $$\tilde{x}^\star \in C$$, the relaxation is **exact**, certifying $$x^\star = (0.6, 0.8)$$ and $$f^\star = -5$$ as the global optimum of the original nonconvex problem.

This section discusses relaxation techniques, which are used to simplify or approximate convex optimization problems by relaxing constraints.

Consider a problem of the form:
>$$\text{min}_{x} \text{ } f(x) \text{  subject to  } x \in C$$

The process of changing the domain set $$C$$ to a superset $$\tilde{C} \supseteq C$$ is known as *Relaxation*.
>$$\text{min}_{x} \text{ } f(x) \text{  subject to  } x \in \tilde{C}$$

Since we are optimizing over a larger domain set than $$C$$, the optimal value of the relaxed problem is always less than or equal to that of the original problem.

### Important special case: relaxing non-affine equality constraints
>$$h_{j}(x) = 0, j = 1, \dotsc, r,$$ where $$h_{j}, j = 1, \dotsc, r$$ are convex but non-affine,
>are replaced with $$h_{j}(x) \le 0, j = 1, \dotsc, r.$$

By transforming equality constraints into inequality constraints, the relaxation technique loosens the constraints and effectively enlarges the domain. When the given equality constraints are convex and non-affine, this method can be used to reformulate the problem as a convex optimization problem. (However, this is under the condition that the same solution is still valid even after the relaxation.)
