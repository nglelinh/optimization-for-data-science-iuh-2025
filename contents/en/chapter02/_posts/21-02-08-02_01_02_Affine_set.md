When you impose linear equality constraints $$Ax = b$$—such as flow conservation in a power grid or portfolio weights summing to 1—the feasible region is a flat slice of $$\mathbb{R}^n$$ that does not necessarily pass through the origin. That shifted flat is an *affine set*. Recognizing that every affine set is just a linear subspace translated by a single feasible point $$x_0$$ lets us eliminate equality constraints cleanly in optimization algorithms.

## Key ideas: Affine Sets and Linear Equalities

- **Closure Under Infinite Lines:** A set $$C$$ is affine if for any $$x_1, x_2 \in C$$ and *all* $$\theta \in \mathbb{R}$$, $$\theta x_1 + (1-\theta)x_2 \in C$$.
- **Affine Combinations & Affine Hull:** The affine hull $$\text{aff}(S)$$ is the smallest flat containing $$S$$—crucial for defining the *relative interior* of lower-dimensional convex sets like the probability simplex.
- **Shifted Subspace Structure ($$C = x_0 + V$$):** Subtracting any single point $$x_0 \in C$$ produces a unique linear subspace $$V = C - x_0$$ independent of the choice of $$x_0$$.
- **Equivalence to $$Ax = b$$:** Every solution set $$\{x : Ax = b\}$$ is affine (with associated subspace $$V = \mathcal{N}(A)$$), and conversely every affine set can be written as the solution set of a linear system.

### Worked example: Decomposing a Line into $$x_0 + V$$

Consider the affine set $$C = \{(x_1, x_2) \in \mathbb{R}^2 : 2x_1 + x_2 = 4\}$$.

1. **Pick any particular point $$x_0 \in C$$:** Setting $$x_2 = 0$$ gives $$x_0 = (2, 0)^T \in C$$.
2. **Identify the associated subspace $$V = C - x_0$$:** For any $$x \in C$$, let $$v = x - x_0$$. Then
   $$2(v_1 + 2) + (v_2 + 0) = 4 \iff 2v_1 + v_2 = 0 \implies V = \text{span}\left\{\begin{pmatrix} 1 \\ -2 \end{pmatrix}\right\}.$$
   Hence $$C = \begin{pmatrix} 2 \\ 0 \end{pmatrix} + \text{span}\left\{\begin{pmatrix} 1 \\ -2 \end{pmatrix}\right\}$$.
3. **Verify closure under an affine combination with negative weight:** Take $$p = (2, 0)^T \in C$$, $$q = (0, 4)^T \in C$$, and $$\theta = 3$$:
   $$3p + (1 - 3)q = 3(2, 0)^T - 2(0, 4)^T = (6, -8)^T.$$
   Checking the defining equation: $$2(6) + (-8) = 12 - 8 = 4$$, confirming $$(6, -8)^T \in C$$.

An affine set is a collection with no boundaries, such as a point, line, plane, or hyperplane. To determine if a set is affine, check if the line passing through any two points in the set is also contained within the set. The absence of boundaries means that if any space has a boundary, it cannot be an affine set. Let's define this mathematically.

## Affine set

A set $$C \subseteq \mathbb{R}^n$$ is an **affine set** if for any two points $$x_1, x_2 \in C$$, the line passing through them is also in $$C$$:
> $$\theta x_1 + (1-\theta)x_2 \in C$$ with $$\theta \in \mathbb{R}$$

This can be interpreted as a linear combination of two points in $$C$$, where the sum of the coefficients is 1. If the result is always in $$C$$, then $$C$$ is an affine set.

## Affine combination

A linear combination of several points where the sum of the coefficients is 1 is called an **affine combination**:
> $$\theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_k x_k \in C$$ with $$\theta_1 + \theta_2 + \cdots + \theta_k = 1$$

If every affine combination of points in a set $$C$$ is also in $$C$$, then $$C$$ is an affine set.

## Affine hull

The set of all affine combinations of points in $$C \subseteq \mathbb{R}^n$$ is called the **affine hull** of $$C$$, denoted as **aff** $$C$$:
> $$ \text{aff} (C) = \{ \theta_1 x_1 + \cdots + \theta_k x_k \mid x_1, ..., x_k \in C, \theta_1 + \cdots + \theta_k = 1 \} $$

## Relationship between affine set and subspace

If $$C$$ is an affine set and $$x_0 \in C$$, then $$V = C - x_0$$ is a subspace:
> $$V = C - x_0 =  \{ x - x_0 \mid x \in C \}$$

Thus, "An affine set $$C$$ is a translation of a linear subspace $$V$$ by $$x_0$$," where $$x_0$$ can be any point in $$C$$. The dimension of $$C$$ is the same as that of $$V$$.

### [Reference] Proof that $$V$$ is a subspace

To prove $$V$$ is a subspace, show that it is closed under addition and scalar multiplication. That is, for $$v_1, v_2 \in V$$ and $$\alpha, \beta \in \mathbb{R}$$, $$\alpha v_1 + \beta v_2 \in V$$. This follows from the definition above.
