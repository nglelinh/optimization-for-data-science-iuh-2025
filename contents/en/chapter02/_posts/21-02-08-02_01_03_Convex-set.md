If an investor holds two compliant portfolios $$x$$ and $$y$$, any blended portfolio $$\theta x + (1-\theta)y$$ ($$0 \le \theta \le 1$$) represents a diversification mix between them. When the set of compliant portfolios is *convex*, diversification never violates the rules. Beyond feasibility, the *convex hull* lets us wrap any scattered or nonconvex set of points inside the tightest possible convex envelope—the foundational trick behind convex relaxations.

## Key ideas: Core Geometry of Convex Sets

- **Line-Segment Closure:** $$C$$ is convex if and only if for all $$x, y \in C$$ and $$\theta \in [0, 1]$$, $$\theta x + (1-\theta)y \in C$$.
- **Convex Combinations as Weighted Averages:** Generalizing to $$k$$ points gives $$\sum_{i=1}^k \theta_i x_i$$ with $$\theta_i \ge 0, \sum \theta_i = 1$$—interpretable as the center of mass (or expectation) of a discrete probability distribution over $$\{x_1, \dots, x_k\}$$.
- **Convex Hull ($$\text{conv}(S)$$):** The set of all finite convex combinations of points in $$S$$—equivalently, the intersection of all convex sets containing $$S$$.
- **Optimization Connection:** Minimizing a linear function over a nonconvex set $$S$$ has the exact same optimal value as minimizing it over the convex set $$\text{conv}(S)$$.

### Worked example: Testing Membership in a 2D Convex Hull

Determine whether the point $$p = (2, 2)^T$$ lies in the convex hull of the triangle vertices $$v_1 = (0, 0)^T$$, $$v_2 = (4, 0)^T$$, and $$v_3 = (1, 4)^T$$.

1. **Set up the convex combination system $$p = \theta_1 v_1 + \theta_2 v_2 + \theta_3 v_3$$ with $$\theta_1 + \theta_2 + \theta_3 = 1$$:**
   - First coordinate: $$0\theta_1 + 4\theta_2 + 1\theta_3 = 2$$.
   - Second coordinate: $$0\theta_1 + 0\theta_2 + 4\theta_3 = 2$$.
2. **Solve sequentially for $$\theta_3, \theta_2, \theta_1$$:**
   - From the second coordinate: $$\theta_3 = \frac{2}{4} = 0.5$$.
   - Substitute into the first coordinate: $$4\theta_2 + 0.5 = 2 \implies \theta_2 = \frac{1.5}{4} = 0.375$$.
   - Use sum-to-one: $$\theta_1 = 1 - 0.5 - 0.375 = 0.125$$.
3. **Check nonnegativity:** Since $$\theta_1 = 0.125 \ge 0$$, $$\theta_2 = 0.375 \ge 0$$, and $$\theta_3 = 0.5 \ge 0$$, $$p$$ is a valid convex combination and lies strictly inside $$\text{conv}\{v_1, v_2, v_3\}$$.

Now let's look at the core concept of this chapter: the convex set. Intuitively, a convex set is a set with no "dents" or "holes" inside. To determine if a set is convex, check if the line segment connecting any two points in the set is also contained within the set.

## Convex set

A set $$C \subseteq \mathbb{R}^n$$ is a **convex set** if for any two points $$x_1, x_2 \in C$$, the line segment connecting them is also in $$C$$:
> $$\theta x_1 + (1-\theta)x_2 \in C$$ with $$x_1, x_2 \in C$$, $$0 \le \theta \le 1$$

This means that for any two points in $$C$$, all points on the line segment between them are also in $$C$$.

## Convex combination

A linear combination of several points where the coefficients are non-negative and sum to 1 is called a **convex combination**:
> A point of the form $$\theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_k x_k$$ with $$\theta_1 + \theta_2 + \cdots + \theta_k = 1, \theta_i \ge  0, i = 1,  ..., k$$

If every convex combination of points in a set $$C$$ is also in $$C$$, then $$C$$ is a convex set.

## Convex hull

The set of all convex combinations of points in $$C \subseteq \mathbb{R}^n$$ is called the **convex hull** of $$C$$, denoted as **conv** $$C$$:
> **conv** $$C = \{ \theta_1 x_1 + \cdots + \theta_k x_k \mid x_i \in C, \theta_i \ge 0, i = 1, ..., k, \theta_1 + \cdots + \theta_k = 1 \}$$
